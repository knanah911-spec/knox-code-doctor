# About KNOX Code Doctor

KNOX Code Doctor is a browser-based workspace for writing, organizing, and checking code. It includes project and conversation history, a code editor, local checks for supported code formats, file import/export, and optional AI-assisted review when the user configures a compatible provider and API key.

## Principles

- **Simplicity:** a focused workspace with a straightforward interface.
- **Privacy-conscious design:** local features run in the browser where supported, and the app does not require a KNOX account.
- **Transparency:** the app's behavior and limitations are documented in the project files.
- **Accessibility:** a responsive layout designed for mobile, tablet, and desktop browsers.

## Important notes

- Local code checks are limited and cannot detect every bug or security issue.
- AI-assisted features require an internet connection and a provider API key. When used, relevant prompts, conversation context, and code sent for review may be transmitted to the selected AI provider and handled under that provider's terms and privacy policy.
- API keys stored in browser storage are not fully secure. Avoid storing sensitive keys on shared or untrusted devices.
