# Privacy Policy — KNOX Code Doctor

**Last updated: 18 October 2026**

## 1. Account and backend

This version is designed to run in the browser and does not require a KNOX account or a KNOX-operated application backend. The hosting provider (for example, GitHub Pages) may process ordinary server logs when you visit a hosted site.

## 2. Browser storage

- Project files, code, conversations, settings, and revision history may be stored in browser storage on the device in use.
- This local data may be lost if browser/site data is cleared, the browser is reset, or the user changes devices. Export important projects as backups.
- API keys may be stored in browser storage by the app. Browser storage is not a secure vault; someone with access to the device or browser profile may be able to retrieve them.

## 3. AI providers

- AI assistance is optional. Local checks alone do not send code or prompts to an AI provider.
- If you configure a provider and send a prompt for review, the relevant prompt, conversation messages, and code context may be sent to that selected provider's API.
- The provider may process or retain data under its own terms and privacy policy. Review those terms before sending confidential information.
- Third-party AI requests require an internet connection, and provider endpoints or availability may change.

## 4. Third-party services

When the app sends a request to an AI provider or other third-party service, that provider may receive connection details or the content needed to fulfill the request. Review the relevant provider's current documentation and privacy policy.

## 5. User responsibility

Do not enter passwords, private keys, confidential source code, personal data, or other sensitive information unless you understand where it will be stored and, for AI features, which provider will receive it.

## 6. Changes and contact

This policy may be updated as the project changes. For questions or privacy concerns, use the repository's Issues page.
