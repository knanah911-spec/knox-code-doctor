About KNOX Code Doctor

KNOX Code Doctor is a browser-based workspace for managing code files, project conversations, revisions, and code reviews. Basic checks run locally in your browser; they are limited and cannot detect every bug.

Privacy

Project files, conversations, and revisions are stored in this browser using local storage technologies. Clearing browser site data may erase them, so export backups regularly.

Your code and prompts are not sent to an AI provider by local checks alone. When you send a message to a configured AI provider, the current file's code and conversation context may be sent to that provider. The provider's privacy policy and terms apply.

API keys stored in browser storage are not fully secure. Do not use shared devices or submit sensitive code unless you understand the risks.

No KNOX account or KNOX-operated app backend is required for this version. Hosting providers and third-party AI providers may process connection information or content as described in their own policies.
