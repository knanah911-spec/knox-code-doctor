# KNOX Code Doctor

KNOX Code Doctor is a single-file, browser-based coding workspace. It is designed to run in a modern browser without a build step or a KNOX-operated server backend.

## Features

- Create and manage projects and conversations
- Edit code and import/export files
- Keep project data and revision history in browser storage
- Run limited local code checks
- Optionally connect a compatible AI provider using your own API key
- English by default, with an option to switch to Arabic
- Light and dark themes

## Getting started

1. Open `index.html` in a modern browser, or publish this repository with GitHub Pages.
2. Start a project and import or write your code.
3. If you choose to use AI features, configure a supported provider and your own API key in the app.

## Important limitations

- Local checks are limited and cannot guarantee that code is correct or secure.
- Projects and history are stored in the browser. Export backups before clearing browser data or changing devices.
- When AI features are used, relevant prompts and code context may be sent to the selected provider. Review that provider's terms and privacy policy.
- API keys stored in browser storage are not fully secure. Avoid storing sensitive keys on shared devices.
